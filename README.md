# InsightLog

ブラウザで動くPWAアプリケーション。

## セットアップ

研修環境は GitHub Codespaces を利用します。

### 開発サーバーの起動

```bash
npm install
npm run dev
```

起動後、http://localhost:5173/ にアクセスしてください（Codespaces ではポートが自動転送されます）。

## 主なコマンド

```bash
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run test     # テスト実行
```

## 技術スタック

React 19 + TypeScript / Vite 7 / Tailwind CSS 4 / Zustand / Dexie.js / Recharts / Vitest
