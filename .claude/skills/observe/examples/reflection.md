## 摩擦ポイント（時間がかかった箇所・噛み合わなかった箇所）

- **何が起きたか**: バイブコーディングで「※必須の赤文字を付与してください」と指示。各フィールドのラベルの font-size を基準に ※必須 のサイズを計算したため、フィールドごとにサイズがバラバラに。期待は全フィールド統一サイズ
- **原因の推定**: prompt — プロンプトに「サイズは統一」が無かった。仕様の曖昧さがそのまま結果のブレに直結
- **どう解消したか**: SDD の Plan 段階で「※必須のフォントサイズをどう決めるか」を明示し、統一サイズで実装

- **何が起きたか**: 新規作成した RequiredBadge コンポーネントが `src/RequiredBadge.tsx` に配置された。既存コンポーネントは `src/components/ui/` にあるが、CLAUDE.md に新規ファイル配置ルールが無かったため AI が推測で配置
- **原因の推定**: config — CLAUDE.md のディレクトリ構成セクションに新規ファイルの配置ルールが不足
- **どう解消したか**: 手動で `src/components/ui/` に移動し import を修正

## 得られた知見

- バイブコーディングは「動くもの」は作れるが「仕様通りのもの」は作れない。仕様の曖昧さが結果のブレに直結する
- SDD の Plan レビューで「フォントサイズの決定方法」を事前確認できた。コードを書く前に仕様の穴が見つかるのが SDD の価値
- CLAUDE.md にディレクトリ構成が書いてあっても、新規ファイルの配置ルールが無いと AI は推測で配置する
