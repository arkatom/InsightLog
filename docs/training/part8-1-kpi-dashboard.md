# 実習: InsightLog の記録を経営層向け報告書に変換する

## ゴール

研修中に InsightLog に記録してきたデータを、**AI 活用の成果を経営層に伝える報告書** に変換する。ここまでの研修で蓄積してきた実績データを初めて「使う」フェーズ。

> **用語メモ**
> - `KPI`（ケーピーアイ / Key Performance Indicator）= 重要業績指標。AI 利用率・工数削減率など、成果を数値で表したもの
> - `CSV`（シーエスブイ）= カンマ区切りのデータファイル。Excel や Google スプレッドシートで開けます
> - `Markdown`（マークダウン）= 見出し・箇条書きなどを `#` や `-` で表すテキスト形式
> - `ダッシュボード` = データを視覚的にまとめた管理画面

## 前提

- [InsightLog](https://insightlog.pages.dev/) に **7件以上** のタスク記録があること
  （記録が少ない場合は、過去の研修実習を追加登録してから始める）

---

## Phase 1: KPI 形式のデータをエクスポートする（5分）

1. [InsightLog](https://insightlog.pages.dev/) を開く
2. 右上の「📊 統計」アイコンをクリック
3. 「KPI形式でエクスポート」ボタンをクリック

ダウンロードされたファイル（`logs.csv`）を確認してください。

> **補足**: CSV ファイルには「タスク名 / AI使用有無 / 所要時間 / 使用ツール / 振り返りメモ」などが入っています。Excel や Numbers で開いて中身を確認してみてください

---

## Phase 2: ダッシュボードにアップロードして可視化する（10分）

1. ブラウザで **https://ax-kpi-dashboard.arkatom.com/** を開く
2. 「CSVファイルを選択」をクリック → Phase 1 でダウンロードしたファイルを選ぶ
3. 4つの指標が自動で計算・表示される:
   - **AI 利用率**: 全タスクのうち AI を使った割合
   - **工数削減率**: AI あり vs AI なしの平均所要時間の差
   - **ツール効果分析**: どの AI ツールが最も工数削減に貢献したか
   - **プロンプト品質**: 手戻り回数が少ないタスクの割合
4. 右上「エクスポート ▾」→「**クリップボードにコピー**」をクリック

> **注意**: データはブラウザ内のみで処理されます。外部サーバーには送信されません

---

## Phase 3: Claude Code で報告書を生成する（15分）

1. Claude Code の入力欄を開き、**Phase 2 でコピーした内容をそのまま貼り付け** て Enter
   （長い Markdown テキストが貼り付けられます）

2. Claude Code が Markdown 冒頭の指示文を読み取り、以下 3 枚の報告書を自動生成します:
   - **概況サマリー**: AI 活用の全体像（1 ページ）
   - **AI 利用内訳**: ツール別・カテゴリ別の効果分析（1 ページ）
   - **改善提言**: 次の一手の提案（1 ページ）

3. 報告書に自部門の情報を追加したい場合は、貼り付け後に以下を追記して Enter:
   ```
   （上のデータに加えて）
   部門: ○○部、メンバー: ○名、主な業務: ○○
   この情報も踏まえて報告書を作ってください。
   ```

> **重要な制約（AI に組み込み済み）**:
> - 数値の捏造禁止（データにない数字を書かない）
> - 因果断定禁止（「AI のおかげで売上 X% 増」のような断言はしない）
> - 業界平均は当日の Web 検索で取得し、出典 URL を明記する

---

## Phase 4: InsightLog に記録する（5分）

[InsightLog](https://insightlog.pages.dev/) に 8 件目の記録として追加してください:

| 項目 | 何を書くか |
|------|-----------|
| タスク名 | KPI ダッシュボード → 経営層向け報告書生成 |
| AIツール | Claude |
| 所要時間 | 実測値 |
| AI 未利用時の推定 | 自力で Excel で集計・Word で報告書を作ったら何分かかるか |
| 手戻り回数 | 指示のやり直し回数 |
| カテゴリ | ドキュメント |
| 振り返りメモ | **特に大事**: 生成された報告書をそのまま上司に出せるか。どこを修正したいか |

---

## 完成の定義

- [ ] Phase 1: InsightLog の「KPI形式でエクスポート」ボタンで `logs.csv` をダウンロードした
- [ ] Phase 2: ダッシュボードで 4 指標を確認し、Markdown をコピーした
- [ ] Phase 3: Claude Code に貼り付けて報告書が生成された
- [ ] Phase 4: InsightLog に 8 件目の記録を追加した

## 詰まったら

- **ダッシュボードにデータが表示されない**:
  - CSV の文字コードが UTF-8 か確認（Windows の Excel で保存すると Shift-JIS になる場合がある）
  - ブラウザのキャッシュをクリアしてページを再読み込み

- **報告書が短い / 内容が薄い**:
  Claude Code に以下を追加指示する:
  ```
  自社の業種と部門規模を具体的に設定して、もう少し詳しく書き直してください
  ```

- **数字が少ないと言われる**:
  InsightLog の記録が 7 件未満。過去の研修実習を追加登録してからやり直す

- **時間内に終わらない**: Phase 2（ダッシュボード確認）まで完了すれば十分。Phase 3 は時間があれば
