# 実習: InsightLog の配色を変える

## ゴール

Claude Code に自然言語で指示を出して、InsightLog の見た目を **自分好みの大胆な配色** に変える。動けばOK・壊れてもOK（リセット可能）。

## 前提

- Claude Code が起動していること
- 別タブで `npm run dev` が動いていて、ブラウザで変更結果を確認できる状態

## 進め方

1. Claude Code のプロンプトに以下をそのままコピペして実行

    ```
    InsightLog の配色を大胆に変えて、インパクトのある見た目にしてください。
    ```

2. しばらく待つ → ブラウザを更新して結果を確認
3. 気に入らなければ追加で指示を出す（例: 「もっと暗い背景で」「ボタンを光らせて」）
4. いい感じになったら、ブラウザのスクリーンショットを撮ってチャットに共有

## 詰まったら

- **同じ画面しかない場合**: ブラウザタブと Claude Code タブを行き来して確認
- **動かない場合**: Claude Code に `元の配色に戻してください` と伝える
- **指示が思いつかない場合**: Claude Code に `どう指示したらいいか教えてください` と聞いても OK

## 完成の定義

- [ ] 見た目が変わったことをブラウザで確認した
- [ ] スクリーンショットをチャットに共有した
- [ ] InsightLog のタスク記録にこの作業を登録した

## 振り返り（記録項目）

InsightLog に以下を記録してください：

| 項目 | 入力例 |
|------|--------|
| タスク名 | Claude Code 初体験 — 配色変更 |
| AIツール | Claude |
| 所要時間 | 実測値 |
| AI 未利用時の推定 | 自力で調べながらやったら何分かかるか |
| 手戻り回数 | 指示のやり直し回数 |
| カテゴリ | デザイン |
| 振り返りメモ | うまくいった点・気づき |
