# 実習: InsightLog をマイ仕様にする

## ゴール

Claude Code に自然言語で指示を出して、研修中ずっと使う InsightLog を **自分仕様** にカスタマイズする。

- A (必ずやる): AI ツールリストを自分が業務で使うものに置き換える
- B (慣れたらやる): カテゴリに自分の業務カテゴリを追加する

## 前提

- Claude Code が起動していること
- 別タブで `npm run dev` が動いていて、ブラウザで変更結果を確認できる状態

## 進め方

### A. AI ツール選択肢を編集 (必ずやる)

Claude Code に以下をコピペ:

```
タスク記録フォームの AI ツール選択肢を、私が業務で使う AI ツールに合わせて編集してください。
私が使うツール: Claude / Copilot / ChatGPT / Gemini / その他AI
※ 「AI未使用」と「Claude」は必ず残してください (Claude の研修なので Claude 必須、計測のため AI未使用 必須)
```

「私が使うツール」 部分は自分用に書き換える。並び替え / 追加 / 削除自由 (ただし「AI未使用」 と「Claude」 は維持)。

### B. カテゴリ選択肢を追加 (慣れたら)

Claude Code に以下をコピペ:

```
タスク記録フォームのカテゴリ選択肢に、私の業務カテゴリを「追加」してください。
追加するカテゴリ: 戦略策定 / 提案資料 / 営業活動 / 顧客対応 / 仕様策定
※ 既存カテゴリ (実装/設計/デザイン/レビュー/調査/ドキュメント/MTG/その他) は後続研修で使うので削除しないでください
```

追加カテゴリは自分の業務に合わせて書き換える。

### 動作確認

1. ブラウザを更新
2. タスク記録フォームを開く (タスク記録ボタン)
3. AI ツール欄 / カテゴリ欄が自分仕様になっていることを確認

## 削除禁止項目 (重要)

| 対象 | 削除禁止 | 理由 |
|------|---------|------|
| AI ツール選択肢 | 「AI未使用」 | KPI 計測の基準値 |
| AI ツール選択肢 | 「Claude」 | 本研修は Claude Code の研修 |
| カテゴリ選択肢 | 既存 8 種 (実装 / 設計 / デザイン / レビュー / 調査 / ドキュメント / MTG / その他) | 後続研修 (Part 3-8) で記録時に使う |

Claude Code が誤ってこれらを削除した場合は「元に戻してください」と指示。

## 詰まったら

- **動かない**: Claude Code に `元に戻してください` と伝える
- **指示が思いつかない**: Claude Code に `どう指示したらいいか教えてください` と聞いても OK
- **エラーが出た**: そのエラーをコピペして Claude Code に「これ直してください」 と投げる

## 完成の定義

- [ ] AI ツール欄が自分仕様になったことをブラウザで確認した
- [ ] (オプション) カテゴリ欄に自分の業務カテゴリが追加された
- [ ] スクリーンショットをチャットに共有した
- [ ] InsightLog のタスク記録にこの作業を登録した

## 振り返り（記録項目）

InsightLog に以下を記録してください:

| 項目 | 入力例 |
|------|--------|
| タスク名 | Claude Code 初体験 — InsightLog マイ仕様化 |
| AIツール | Claude (+ 他に使ったもの) |
| 所要時間 | 実測値 |
| AI 未利用時の推定 | 自力で `aiTools.ts` を編集したら何分かかるか |
| 手戻り回数 | 指示のやり直し回数 |
| カテゴリ | その他 (または「設定」を新規追加した場合はそれ) |
| 振り返りメモ | うまくいった点・気づき・既存維持指示の効き目 |

## 後続研修との接続
