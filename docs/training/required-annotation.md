# 実習: 必須フィールドの注釈表示

## ゴール

同じお題を **バイブコーディング（プロンプト一発）** と **SDD（仕様駆動開発）** の2つの方法で実装し、結果の違いを体感する。

## 前提

- Claude Code が起動していること
- 別タブで `npm run dev` が動いていて、ブラウザで変更結果を確認できる状態
- `docs/specs/` 配下に Issue ファイルとデザイン画像が配置されていること

## お題

タスク記録フォームの必須フィールドに「※必須」の赤文字を付与する。

## Step 1: バイブコーディング（10分）

1. Claude Code のプロンプトに以下をそのままコピペして実行

    ```
    タスク記録フォームの必須フィールドに「※必須」の赤文字を付与してください
    ```

2. 実装が走り終わったら `npm run dev` でブラウザを確認
3. 期待通りの結果になったか確認する

    **チェックポイント**: 全フィールドで「※必須」の文字サイズは統一されていますか？ バラバラになっていませんか？

## Step 2: リセット

バイブコーディングの変更を全て取り消す:

```bash
git checkout -- .
```

## Step 3: SDD で再実装（30分）

1. `/plan` で Plan モードに切り替え

2. デザイン画像を **Shift+ドラッグ&ドロップ** で Claude Code に渡し、以下のプロンプトを入力:

    ```
    この Issue と画像の通りに必須フィールドの注釈表示を実装してください。実装後、Playwright MCP でスクリーンショットを撮って外観を確認してください。
    ```

    Issue ファイルの場所は講師から案内されます。

3. AI が Plan を出力したら **レビュー**:
   - どのフィールドが必須と判定されているか
   - ※必須のフォントサイズはどう決められているか
   - ラベルなしフィールドの配置方法

4. 問題なければ Plan を承認 → 実装が走る

5. `npm run dev` でブラウザ確認

## 完成の定義

- [ ] バイブコーディングで実装してブラウザで確認した（Step 1）
- [ ] git checkout で変更をリセットした（Step 2）
- [ ] SDD（Plan モード）で再実装してブラウザで確認した（Step 3）
- [ ] InsightLog に振り返りメモまで書いて記録した

## 詰まったら

- **Plan モードの切り替え方がわからない**: `/plan` と入力
- **デザイン画像の渡し方がわからない**: Shift キーを押しながら画像ファイルをドラッグ&ドロップ
- **Plan の内容がよくわからない**: 「※必須のフォントサイズが全フィールドで同じか」に注目
- **時間内に終わらない**: SDD の Plan レビューまで体験できれば十分。実装完了は必須ではない
