# 実習: 必須フィールドの注釈表示

## ゴール

同じお題を **バイブコーディング（プロンプト一発）** と **SDD（仕様駆動開発）** の 2 つの方法で実装し、結果の違いを体感する。さらに [InsightLog](https://insightlog.pages.dev/) に振り返りを記録する。

## 前提

- Claude Code が起動していること
- `docs/plans/` 配下に Issue ファイルとデザイン画像が配置されていること
  - `docs/plans/必須フィールドにバリデーション表示を追加.issue.md` — お題
  - `docs/plans/必須デザイン期待値_デザイナーコメントあり.png` — 期待値画像

## お題

タスク記録フォームの必須フィールドに「※必須」の赤文字を付与する。

---

## Phase 1: バイブコーディングで作る（10 分）

プロンプト一発でどんな結果になるかを体感するフェーズ。

1. Claude の入力欄に以下をそのままコピペして実行

    ```
    タスク記録フォームの必須フィールドに「※必須」の赤文字を付与してください
    ```

2. 実装が終わったら開発環境を起動（`!` を先頭に付けるとコマンドとして直接実行される）:

    ```
    !npm run dev
    ```

3. **Codespaces を使っている場合**、ポート 5173 の公開設定を聞かれたら **Public** を選ぶ（VS Code 下部「ポート」タブで 5173 を右クリック → ポートの可視性 → Public）。Private のままだと CORS エラーでブラウザが真っ白になる。

4. ブラウザで結果を確認する

    **チェックポイント**: 全フィールドで「※必須」の文字サイズは統一されていますか？ バラバラになっていませんか？

---

## Phase 2 に入る前: リセット

Phase 1 の変更を全て取り消す。Claude の入力欄で以下を実行:

```
!git restore .
```

---

## Phase 2: SDD で作り直す（30 分）

1. **Plan モードに切り替える**: Claude の画面表示が `Plan` になるまで **Shift + Tab** を押す（今のモードによって押す回数が変わる）

2. **お題ファイルとデザイン画像を両方 Shift+ドラッグで添付する**:
    - ファイルは `docs/plans/` 配下:
      - `docs/plans/必須フィールドにバリデーション表示を追加.issue.md` — お題
      - `docs/plans/必須デザイン期待値_デザイナーコメントあり.png` — 期待値画像
    - 両方のファイルを **Shift キーを押しながら** Claude の入力欄にドラッグ＆ドロップ（= 添付）
    - 以下のプロンプトをコピペ:

        ```
        添付した Issue ファイルと画像の通りに、必須フィールドの注釈表示を実装してください。実装後、Playwright MCP でブラウザを立ち上げてスクリーンショットを撮り、外観が画像通りか確認してください。
        ```

3. Claude が Plan を出力したら **レビュー**:
    - どのフィールドが必須と判定されているか
    - ※必須のフォントサイズはどう決められているか（**全フィールドで同じ指定になっているか**が確認ポイント）
    - ラベルなしフィールドの配置方法

4. 問題なければ Plan を **承認** → 実装が走る

5. Phase 1 で開いた開発環境のタブを更新して、画像と同じ見た目になっているか確認する

---

## Phase 3: 見比べて [InsightLog](https://insightlog.pages.dev/) に記録する（5 分）

1. Phase 2 の結果をブラウザで確認 — ※必須の文字サイズは全フィールドで統一されているか？
2. Phase 1 の結果を思い出して見比べる — バラバラだったバイブの結果と、Plan を通した SDD の結果の差を体感する
3. [InsightLog](https://insightlog.pages.dev/) を開いて新しいタスクを追加
4. 記録項目を入力:

    | 項目 | 何を書くか |
    |------|-----------|
    | タスク名 | 必須フィールドの注釈表示（バイブ + SDD） |
    | AI ツール | Claude |
    | 所要時間 | 実測値 |
    | AI 未利用時の推定 | 自力で調べながらやったら何分かかるか |
    | 手戻り回数 | 指示のやり直し回数 |
    | カテゴリ | UI改善 |

5. **振り返りメモ** — 「Plan でバイブコーディング時の問題に気づけたか？」を書く

## 完成の定義

- [ ] Phase 1: バイブコーディングで実装して、ブラウザで結果を視認した
- [ ] Phase 2: `!git restore .` でリセット後、Plan モード + 画像 + Issue で再実装、ブラウザで結果を視認した
- [ ] Phase 3: [InsightLog](https://insightlog.pages.dev/) に振り返りメモまで書いて記録した

## 詰まったら

- **Plan モードに切り替わらない**: 画面下部の表示が `Plan` になるまで **Shift + Tab** を押す（今のモードによって押す回数が変わる）
- **ファイルの添付方法がわからない**: **Shift キーを押しながら** ファイルを Claude の入力欄にドラッグ＆ドロップする。添付すると入力欄の上に添付リストが表示される。画像と Markdown どちらも同じ方法で添付できる
- **ブラウザが真っ白になる**: Codespaces のポート 5173 が Private のまま。VS Code 下部「ポート」タブで 5173 を右クリック → ポートの可視性 → **Public**
- **Plan の内容がよくわからない**: 「※必須のフォントサイズが全フィールドで同じか」に注目する
- **時間内に終わらない**: Phase 2 の Plan レビューまで体験できれば十分。Phase 2 の実装完了は必須ではない
