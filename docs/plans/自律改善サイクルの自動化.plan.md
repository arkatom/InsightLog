# 自律改善サイクルの自動化

observe/evolve スキルの自動実行を settings.json の hooks に追加して自律的にサイクルが回るようにする。

---

## 自動化の全体像

```
セッション作業 → Stop hook (prompt判定) → /observe 自動実行
                                              ↓
                              振り返り記録 + Rubric 採点 + 改善提案
                                              ↓
                              /evolve (手動 or /loop 30m)
                                              ↓
                     ┌────────────┴────────────┐
                 low-risk                    high-risk
                 自動適用                    人間キュー
                     ↓                          ↓
                 verified 検証              ユーザー判断
                     ↓
              cycle-health チェック
              (スコア下降 → ロールバック)
```

---

## 実装項目 A: Stop hook で observe を自動トリガー

settings.json の `hooks` セクションに以下を追加する:

```json
{
  "Stop": [
    {
      "matcher": "",
      "hooks": [
        {
          "type": "prompt",
          "prompt": "セッション終了判定。以下のルールで判定せよ:\n1. stop_hook_activeがtrueなら {\"ok\": true}\n2. 直前のアシスタントメッセージに OBSERVE: / OBSERVE_OK / EVOLVE: / EVOLVE_OK が含まれるなら {\"ok\": true}\n3. セッションで意味のある作業（ファイル編集、コミット等）があったなら {\"ok\": false, \"reason\": \"/observe を実行してセッションを振り返ってください\"}\n4. 軽微な質問・会話のみなら {\"ok\": true}",
          "timeout": 30
        }
      ]
    }
  ]
}
```

### 仕組みの解説

- **`type: "prompt"`**: 軽量な LLM 判定。セッション終了のたびに haiku レベルのモデルが30秒以内に判定する
- **`stop_hook_active`**: Claude が Stop hook の reason に従って作業を続行した場合、次の Stop イベントでこのフラグが true になる。これにより「observe 実行 → また Stop → また observe」の無限ループを防止する
- **条件2**: observe/evolve の出力キーワード（OBSERVE_OK 等）が直前のメッセージに含まれていれば、既に振り返り済みなのでスキップ
- **条件3**: ファイル編集やコミットなど意味のある作業があった場合のみ observe を促す
- **条件4**: 軽い質問や会話だけのセッションでは observe を実行しない（不要なログを防止）

---

## 実装項目 B: /loop で evolve を定期実行

セッション中に以下を実行する:

```
/loop 30m /evolve
```

30分ごとに evolve が実行される。proposed がなければ即 `EVOLVE_OK` で終了するため、負荷は最小。

### /loop の特性

- セッション内でのみ有効（セッション終了で停止する）
- デフォルト間隔は10分。`30m` で30分間隔を指定
- evolve の早期終了チェック（proposed = 0 なら即終了）により、無駄な実行コストはほぼゼロ

---

## 実装項目 C: 自動化の検証手順

1. settings.json に Stop hook を追加する
2. 意味のある作業（ファイル編集、コミット等）を行う
3. Claude の応答が完了したとき、Stop hook が発火して「/observe を実行してセッションを振り返ってください」と表示されることを確認
4. observe が完了し、OBSERVE_OK が表示されること
5. 次の Stop では `{"ok": true}` が返り、無限ループしないことを確認
6. `/loop 30m /evolve` を開始し、30分後に自動で evolve が実行されることを確認

---

## 注意事項

- Stop hook の prompt は日本語で書かれているが、判定ロジックは英語の JSON を返す必要がある
- timeout: 30 を超えるとデフォルトで `{"ok": true}` が返る（安全側に倒れる）
- 自動化がうまく動かない場合は、settings.json から Stop hook のエントリを削除すれば即座に無効化できる
