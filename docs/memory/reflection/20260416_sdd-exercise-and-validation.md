## 摩擦ポイント（時間がかかった箇所・噛み合わなかった箇所）

- **何が起きたか**: バイブコーディングで「※必須の赤文字を付与してください」と指示したところ、各フィールドのラベルの font-size を基準に ※必須 のサイズを計算したため、フィールドごとにサイズがバラバラになった。期待は全フィールドで統一サイズだった
- **原因の推定**: prompt — プロンプトに「サイズは統一」という指定がなかった。仕様が曖昧だった
- **どう解消したか**: SDD で Plan を立てた段階で「※必須のフォントサイズをどう決めるか」が明示され、統一サイズで実装された

- **何が起きたか**: SDD 再実装後に Playwright MCP でスクリーンショットを撮ったが、npm run dev を実行し忘れていてスクショが古い状態のままだった。2回撮り直し
- **原因の推定**: procedure — 実装後に dev サーバーを再起動する手順が抜けていた
- **どう解消したか**: npm run dev を実行してから再度スクショ

- **何が起きたか**: 新しく作った RequiredBadge コンポーネントが src/RequiredBadge.tsx に配置された。既存コンポーネントは src/components/ui/ にあるのに、CLAUDE.md に「新規コンポーネントは src/components/ui/ に配置」と書いてなかったので AI が src/ 直下に作った
- **原因の推定**: config — CLAUDE.md のディレクトリ構成セクションに新規ファイルの配置ルールが不足
- **どう解消したか**: 手動で src/components/ui/ に移動し、import を修正

- CLAUDE.md にディレクトリ構成が書いてあっても、「新規ファイルをどこに置くか」のルールがないと AI は推測で配置する
